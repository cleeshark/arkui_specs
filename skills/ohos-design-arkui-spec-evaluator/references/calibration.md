# Optional Calibration

Load this reference only when the user explicitly requests comparison with a prior confirmed
Review. A clean evaluation does not require this reference.

Freeze and validate the blind automatic result before opening any confirmed Review. Compare the
automatic run with the prior Review using:

- Criterion conclusion agreement.
- Critical and Major finding recall by problem substance.
- Severity agreement.
- Unsupported extra finding count.
- Missing-evidence rate.
- Repeated-run score or deduction variance.

Finding IDs need not match when the same problem, scope, and evidence are identified. Never overwrite
the confirmed Review with an automatic result.
